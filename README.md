# تمريني — تطبيق تمارين النادي

تطبيق ويب تقدّمي (PWA) باللغة العربية يُثبَّت على الجوال من المتصفح ويعمل دون إنترنت داخل النادي.

## الواجهات الأربع (شريط التبويبات)
| التبويب | الوظيفة |
|---|---|
| **الرئيسية** | خريطة جسم تفاعلية (أمامي/خلفي). اختر عضلة أو أكثر ثم «ابدأ» للانتقال لتمرينها. |
| **التقويم** | عرض أسبوعي (الأحد ← السبت) بالتاريخين الميلادي والهجري، التمارين المنجزة والمجدولة، وإحصاءات الأسبوع. |
| **التمارين** | مستودع التمارين الذي يضيفه المدير من لوحة التحكم، بثلاث طرق عرض، وبحث بالعربي أو الإنجليزي، وفلترة بالعضلة والأداة. |
| **الإعدادات** | وحدة الوزن، مدة الراحة، الجولات والتكرارات الافتراضية، GIF، نسخ احتياطي واستيراد. |

## مسار الاستخدام
1. اختر العضلة من خريطة الجسم ← «ابدأ».
2. إن لم توجد خطة محفوظة: «خطّط تمرينًا لهذه العضلات» ← يُفتح مستودع التمارين مُفلترًا بالعضلة.
3. اختر التمارين وحدد الجولات والتكرارات ← «حفظ وابدأ».
4. سجّل الوزن والتكرار لكل جولة؛ مؤقت الراحة يعمل تلقائيًا بعد كل جولة.
5. «إنهاء وحفظ» ← يظهر التمرين في التقويم، وتُقترح أوزانك السابقة في المرة القادمة.

## التشغيل
تطبيق ثابت بلا خطوة بناء:
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```
للاستخدام على الجوال: انشره على أي استضافة ثابتة (مثل GitHub Pages)، افتحه في Safari ثم «مشاركة ← إضافة إلى الشاشة الرئيسية».

## مصادر البيانات
- **لا يوجد مستودع تمارين مدمج.** كل التمارين وصورها يضيفها المالك/المحرر من **لوحة تحكم التمارين**.

## تسهيل الاختيار
- **★ المفضلة**: نجمة على صورة أي تمرين؛ المفضلة تظهر أولًا في كل القوائم، ويمكن عرضها وحدها.
- **الأجهزة والكيبل فقط**: فلتر سريع لتمارين الأجهزة الأكثر استخدامًا في النادي.
- **إخفاء الإطالات والتمارين الأولمبية/السترونغ مان** افتراضيًا، مع زر لإظهارها؛ وتظهر دائمًا عند البحث بالاسم.

## توزيع التمارين على الأسبوع
- زر **＋** أعلى التقويم يفتح «توزيع التمارين على الأسبوع»: سبعة أيام (الأحد ← السبت)، ولكل يوم زر ＋ لإضافة خطة.
- عند الإضافة تختار: **🔁 كل [اليوم]** (برنامج ثابت يتكرر كل أسبوع) أو **هذا اليوم فقط**.
- بطاقة «برنامج الأسبوع» في التقويم تعرض خطة كل يوم، وتتحول إلى ✓ عند إنجازها.

## أجهزة ناديك (Technogym أو غيرها)
- في صفحة أي تمرين: **«📷 صوّر الجهاز في ناديك»** — تحل صورتك محل الصورة التوضيحية في كل مكان، وتبقى «طريقة الحركة» متاحة.
- في تبويب التمارين: **«أضف جهازًا من ناديك»** — جهاز جديد بصورته واسمه (عربي/إنجليزي) والعضلات المستهدفة وملاحظاتك.
- أجهزة ناديك تظهر بعد المفضلة مباشرة في كل القوائم. الصور محفوظة على الجهاز (IndexedDB) وتدخل في النسخة الاحتياطية.

## لوحة تحكم التمارين (للمالك والمحررين)
- تُفتح من **الإعدادات ← لوحة تحكم التمارين** (تظهر للمالك والمحررين فقط)، وتعمل على الرابط المنشور في claude.ai.
- **خريطة الجسم** (أمامي/خلفي): اختر العضلة فتظهر تمارينها؛ العضلات التي لها تمارين ملوّنة. زر **«إضافة تمرين لـ<العضلة>»**.
- لكل تمرين: الاسم بالعربي والإنجليزي، العضلات الأساسية والمساعدة، الأداة، نص تعريفي حر، وصور/مقاطع (سحب وإفلات، ترتيب، صورة رئيسية، حذف).
- **الفيديو**: MP4 / MOV / WebM؛ يُحوَّل افتراضيًا داخل المتصفح إلى **GIF متحرك** (حتى ٨ ثوانٍ، ٤٨٠ بكسل) عبر `gifenc` (MIT، `js/vendor/`)، أو يُرفع كما هو ويُعرض صامتًا متكررًا.
- التخزين: `exercises/<id>` في قاعدة بيانات الصفحة (`name, ar, primary[], secondary[], equipment, desc, images[], kinds{}`) والصور في مخزن أصولها؛ القراءة للجميع والكتابة للمحررين فقط.
